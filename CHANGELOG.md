# Changelog

Uma seção por versão, no formato `## [x.y.z] - AAAA-MM-DD`. O texto da seção vira o corpo da release no GitHub.

## [0.5.0] - 2026-10-16

Primeira versão publicada.

- Grafo de commits com lanes, branch em destaque e linha tracejada do HEAD ao WIP.
- Painel do commit, WIP com stage por trecho, diff e editor de conflito.
- Desfazer e Refazer de Operações, com histórico persistido.
- Menu de contexto de arquivo e pasta do commit com cópia do comando `git restore`.
- Atualização automática pelo GitHub Releases: o ícone na barra inferior aparece quando há uma versão mais nova.
