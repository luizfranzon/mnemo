# Grafo de commits próprio, com lanes calculadas no core

O grafo não usa lib pronta (react-git-log, commit-graph, @gitgraph/react). O `mnemo-core` calcula as lanes de forma incremental, para que o lazy load de mais commits não faça as lanes já desenhadas pularem, e recalcula ao ocultar, solo ou destacar uma branch (a Branch em destaque ocupa a lane 0). Ele entrega, por commit, os segmentos prontos (lane de entrada/saída e cor). A UI só desenha um SVG por linha virtualizada (TanStack Virtual), seguindo a geometria de `docs/design/03-telas.md`. As libs calculam lanes em JS, impõem layout e colunas próprias e não fazem lazy load incremental. Adaptá-las seria manter um fork. As referências de algoritmo são o crate `git-graph` (mlange-42) e o react-git-log.
