# Remotos

- Adicionar (`git remote add` + fetch opcional), editar nome e URLs (`git remote rename`, `set-url`, `set-url --push`), remover (`git remote remove`, confirma e avisa que as refs remotas somem).
- Mudanças em remotos não são Operações desfazíveis.
- Fork e criação no serviço ficam fora (integrações são v2).
