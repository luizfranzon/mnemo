# Git LFS

- Detectar LFS pelo `.gitattributes` (`filter=lfs`) e pela presença de `git lfs` no PATH; avisar na abertura se faltar.
- Seção LFS nas Preferências do repositório: iniciar (`git lfs install --local`), padrões (`git lfs track/untrack`), comandos pull/push/fetch/prune.
- Menu do arquivo: "Rastrear com LFS" (arquivo, extensão, pasta).
- Prioridade v2 em `01-features.md` § 12.
