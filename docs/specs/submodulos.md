# Submódulos

- Breadcrumb `repositório › submódulo` com voltar ao pai (`01-features.md` § 2); cada nível tem HEAD, WIP e Histórico de Operações próprios (CONTEXT.md).
- Seção Submódulos com estado e ações: iniciar, atualizar (`git submodule update --init --recursive`), abrir, editar URL (`set-url` + `sync`), adicionar, remover (`deinit` + `rm`).
- "Manter submódulos atualizados" é preferência.
- Mudança de ponteiro do submódulo aparece no WIP e se commita como qualquer arquivo.
