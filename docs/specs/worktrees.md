# Worktrees

- Aba = diretório de trabalho (CONTEXT.md): abrir worktree abre ou foca a aba dele.
- Criar (`git worktree add`), travar/destravar, remover (com força só após confirmar), podar.
- Checkout de branch presa em outro worktree oferece abrir esse worktree.
- Operações de worktree não são desfazíveis; remover com a branch avisa que a branch também não volta. Nada de integração com agentes (AGENTS.md).
